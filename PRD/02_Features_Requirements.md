# MedGuard AI — Feature requirements

## Core workflow
1. A visitor understands the product value.
2. A user creates or selects the required input.
3. The system validates the input and provides a clear result.
4. The user can review, revise, and export or save the result.

## Functional requirements
| Priority | Requirement | Acceptance signal |
|---|---|---|
| P0 | Primary creation flow | A new user completes the main action. |
| P0 | Clear loading, empty, and error states | Each state explains the next action. |
| P1 | History or recovery path | Work can be resumed safely. |
| P1 | Export or sharing flow | Output is portable and readable. |

## Non-goals
Avoid features that do not improve the first release’s primary user outcome.
